# DevOps on Fire · Legal

Privacy policy and terms of use for the DevOps on Fire game, published with GitHub Pages:

Plain static HTML, no build step. To publish: **Settings → Pages → Deploy from a branch → `main` / root**.

When a game release changes data handling (network access, analytics, ads, saved progress, new permissions), update `privacy.html` and its effective date before shipping.
